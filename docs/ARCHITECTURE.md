# 架构

技术栈：Vite + React + Electron + TypeScript + Python。

## 代码结构

| 目录 | 职责 |
| --- | --- |
| `apps/desktop/src/` | React 界面：创作台、作品集、音色库、演绎指导、生成记录与设置 |
| `apps/desktop/electron/` | 桌面窗口、文件选择、受限预加载接口与退出清理 |
| `apps/desktop/host/` | 本地接口、工作区保存、资源安装、任务调度与音频管理 |
| `packages/contracts/` | 界面与宿主共用的 TypeScript 数据类型及命令 |
| `services/python/` | 模型下载与推理；`vendor/breeze/` 保留上游源码及许可 |
| `assets/brand/` | 原创图标及导出素材 |
| `scripts/`、`tests/` | 开发、构建、打包脚本与自动检查 |
| `licenses/`、`docs/` | 许可来源与项目文档 |

## 合成流程

```text
React 界面 → 本地宿主 → Python 推理 → 宿主保存 WAV → 界面试听与另存为
```

宿主把文稿、音色和演绎指导固定为任务输入；Python 通过 JSON 行协议返回音频块，宿主保存音频与生成记录。任务按候选串行执行，中断后保留已完成音频，重试只补未完成部分。草稿独立保存，编辑不会改变已提交任务。

## 运行目录

| 目录 | 内容 |
| --- | --- |
| `.runtime/` | uv、Python、推理依赖、缓存与临时文件 |
| `models/` | 在设置中下载的模型权重 |
| `data/` | 作品、参考录音、生成音频、设置与日志 |

运行资源和数据均保存在项目或解压目录内，不使用系统 Python、uv 或外部模型。录音导入与音频另存为经用户选择后复制文件，不保留外部路径依赖。

Electron 启用沙箱和上下文隔离；本地接口仅监听回环地址并检查写请求来源。界面不能直接执行命令或任意读写文件。

## 构建与分发

`npm run dev` 先确认本地工作区服务就绪，再启动 Vite 与客户端。关闭窗口或中断开发进程时先保存编辑，再停止预览，等待工作区服务和本次启动的子进程退出。Python 模型服务由设置中的开关独立控制；工作区接口就绪不代表模型已加载。`npm run test:dev` 在项目内隔离工作区验证连续启动与退出。

`npm run build` 输出至 `build/`；`一键打包.cmd` 检查、构建并将免安装 ZIP 输出至 `release/`。

ZIP 包含 Electron、应用代码、图标和许可文件。uv、Python、推理依赖与模型由用户在设置中安装，用户数据不随包分发。
