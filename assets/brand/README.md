# OpenUI 图标

独立社区客户端标识：松绿底、白色弧形开口与三条声音波形。通用竖向节奏轻微参考模型品牌的声音概念；没有使用或描摹官方 logo，不代表官方授权或背书。

- `logo.svg`：1024 方形坐标，可编辑矢量主文件。
- `logo.png`：1024×1024，透明外边缘。
- `icon-{16,24,32,48,64,128,256}.png`：小尺寸使用。
- `app.ico`：上述七档尺寸，Windows 应用图标。

颜色：松绿 `#315f49`、白色 `#ffffff`。不拉伸、不加阴影或渐变，不与官方 logo 合并。Markdown 可使用 `<img src="assets/brand/logo.svg" width="80" height="80" alt="OpenUI 社区客户端图标" />`。

编辑主文件后运行 `npm run brand:build` 更新导出和应用 public 目录。图标按本项目 Apache-2.0 授权；官方名称和商标的权利不包含在内。许可说明见 `docs/LICENSING.md`，打包时保留 `LICENSE` 与 `NOTICE`。

创作记录：AI 协助探索“开放声音”概念；生产图形为本项目独立编写的 SVG。概念稿不随产品分发。
